# 🤖 AI Student Assistant — CodSoft Task 1

A rule-based AI Student Assistant chatbot built with Python and Streamlit for the CodSoft Artificial Intelligence Internship.

## 🎯 Objective
Build a simple chatbot that uses predefined rules, pattern matching, and basic NLP-style text normalization to understand common student queries and provide relevant responses.

## ✨ Features
- Rule-Based NLP and pattern matching
- Interactive chat interface
- Python assistance
- Data Science assistance
- Machine Learning assistance
- Internship and project guidance
- Study tips and course guidance
- Quick question buttons
- Clear Chat functionality
- Responsive Streamlit UI

## 🛠️ Technologies
- Python
- Streamlit
- Regular Expressions (`re`)
- Rule-based NLP / pattern matching

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run AI_Student_Assistant.py
```
